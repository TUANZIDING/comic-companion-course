LESSON 05 / 11

AI生图实战

先给图片一个明确任务

把画面描述、参考范围和排版空间写清楚，控制返工预算。

本课目标

1. 使用场景、动作、构图和约束组织提示词。

2. 为后续矢量气泡预留空间。

3. 区分澄清描述与绕过服务限制。

讲解

1

一张图只承担一个主要动作

先写谁在什么场景做什么，再写表情、机位、配色和4:3构图。对服装、道具数量等硬约束逐条列出。把最终英文交给排版层，提示图片NO text。

2

裁切要保留信息

4:3是插画框比例，不是整页PDF的比例。裁切前标出脸、手、道具与找物目标，不能为了填满框把关键部分切掉。气泡留白是构图约束，不是在图片里生成随机英文。

3

拒绝时先查原因，再选替代

不同服务的拒绝行为不同，不能说角色名一定会被拒。使用中性外观描述澄清合法场景；遇到不允许的请求停止或换成允许的原创素材。最多尝试一次重画作为预算，仍失败则转人工处理并记录。

真实页面案例

问题

六格包含不同动作，生成文字、气泡位置与裁切都可能带来错误。

可能原因 / 分析

插画和文字排版混在一个不可分离的生成任务里。

修正方法

按格生成无字图，台词在排版层统一添加；检查脚印、人物、留白和裁切后再组版。

本案例为局部抽样，修正方法是教学建议，不代表原PDF已经修订。

可复制提示词

教学示例，非原始制作记录

Generate one original comic illustration using only the lawful reference material supplied.
Reference and permitted scope: [fill in, or mark pending].
Character appearance: [fur, body shape, facial features].
Current clothing and prop state: [fill in].
Scene and single main action: [fill in]. Expression: [fill in].
Composition: 4:3, keep the full face, hands and key prop visible; leave clean space at the top for a later speech bubble.
NO text, NO letters, NO speech bubbles, NO watermark. Dialogue will be added separately.
If the subject is the 1926 Winnie-the-Pooh adaptation, do not use Disney character designs, the red T-shirt or Disney images as references.
Do not recreate protected third-party imagery. If the request is not permitted, explain the issue instead of attempting to bypass it.
This is a teaching example, not the original production prompt.
