# 本地交付检查 v1.0

日期：2026-10-13。目录：`comic-companion-course/`。本轮仅完成静态课程、本地资源与检查。没有在此目录初始化Git，没有创建远端仓库、提交、推送或开启Pages。此交付报告是本地工程检查记录，不能代替书稿全书内容审核、教材审核或各地区使用权核查。

## 交付内容

首页与00–11共12课；共用CSS/原生JS；12张实际PDF截图；两本带版本原版副本与小于10MB的预览；能运行的5页ReportLab教学示例；中英说明、许可、素材说明、检查证据与逐文件大小清单。原PDF原路径与原名保持不变，收尾再次核对源文件SHA-256一致。

本地入口：`http://127.0.0.1:8875/`。服务器以`python3 -m http.server 8875 --bind 127.0.0.1`运行；Chrome实际浏览器访问与自动检查都使用HTTP。网页内容、字体、图片和PDF无外部CDN依赖；外部来源链接需要联网。直接打开文件不能替代HTTP检查，也不宣称网站具有Service Worker缓存。

完整目录树、每个文件字节数和最终总大小见[文件清单v1.0](%E6%96%87%E4%BB%B6%E6%B8%85%E5%8D%95v1.0.md)。
