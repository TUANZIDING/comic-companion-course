This local static HTML course has twelve Chinese lessons for medical researchers and AI learners. Reader profiles and medical cases are fictional. All newly written prompts and code are labelled “Teaching example, not the original production record.”

## Start locally

From the repository folder:

```sh
python3 -m http.server 8875 --bind 127.0.0.1
```

Open `http://127.0.0.1:8875/` in Chrome. Assets, styles, scripts, PDFs and fonts do not depend on external CDNs. The entire local folder can be used without an internet connection while the local server runs; external reference links require internet access. Test clipboard interactions over HTTP, not just a file URL.

## Run the teaching example

The script directly depends only on reportlab and the Python standard library. Installing reportlab also installs its own dependencies. No private source scripts, model accounts, external images or system font files are required. Built-in Helvetica and explicit illustration placeholders demonstrate the English layout; Chinese teaching notes remain in JSON and the course pages.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r examples/示例依赖v1.0.txt
.venv/bin/python examples/排版示例v1.0.py
```

Run from the repository root. Windows users should use the virtual environment's Scripts/python executable. The default input is examples/章节数据v1.0.json and the output is examples/输出/五页排版示例v1.0.pdf. Optional arguments: --data PATH and --output PATH.

## Deliverables

The course covers reader configuration, selection and rights, adaptation, character continuity, image prompts, five-page design, ReportLab, quality review, family use, medical transfer and a final assignment. Each lesson contains goals, explanation, an actual PDF screenshot, a teaching prompt, checklist and exercise.

The existing Winnie-the-Pooh companion has 50 pages / ten chapters, with a 29.6MB copy and an 8.65MB preview. The Peter Rabbit companion has 20 pages / four teaching units, with a 12.9MB copy and a 3.89MB preview. Originals are unchanged. Twelve screenshots are compressed below 300KB each. Preview copies reduce illustration precision while retaining the text layer and page count. Sampled content issues remain documented; this is not a whole-book quality sign-off.

## Rights and missing records

CC BY-NC 4.0 covers only newly written course text and code. Third-party materials, original book content and illustrations, AI-generated imagery, book PDFs and their screenshots are excluded. Gutenberg catalog entries describe US public-domain status. China mainland and other regional status remain pending review. Only the 1926 Milne text / Shepard illustrations are discussed for Winnie-the-Pooh; Disney designs, including the red T-shirt, must not be used as references.

Actual curriculum lists, original cast sheets, generation-tool terms and original prompt records have not been supplied. Visible pending-material panels and the delivery report preserve these gaps. No learner numbers, endorsements or learning-effect data are invented.
