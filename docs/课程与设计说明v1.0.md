# 课程与设计说明 v1.0

本课程为教学新写；提示词与代码标注“教学示例，非原始制作记录”。原始素材只使用两本指定PDF的实际截图。

设计：暖色绘本式教学网站；奶油纸张、森林绿与蜂蜜黄。字号以16–17px正文起步，标题随视口变化；8px间距节奏；卡片圆角20–28px；轻阴影；微动效尊重减少动态设置。适用桌面、平板与手机。

版式：宽幅首页、真实页面双列主视觉、作品画廊、双书下载、课程目录、讲者与FAQ。课程页提供内容目录、六个教学段落、待补充框、完成勾选和上下课入口。

交互：复制反馈、截图放大与键盘关闭、深浅主题、本机进度。没有外部CDN、统计脚本、字体请求或账户服务。本地静态服务器可在断开互联网时浏览；外部依据链接需要互联网。

范围：只完成本地交付。未创建远端、未推送、未启用Pages。
00. 课程导览：从两本现有伴读PDF认识五页结构，把作品、来源和质量检查分开。
01. 从孩子出发：用虚构读者A做示范，将兴趣、词汇和句长变成可修改的设置。
02. 选书与版权：把文本、原著插画、生成图像和课程自有内容分别记录。
03. 拆章与改编：将一个事件变成有动作、反应和阅读顺序的分镜。
04. 角色设定与一致性：角色卡固定外形，连续性表记录服装和道具的变化。
05. AI生图实战：把画面描述、参考范围和排版空间写清楚，控制返工预算。
06. 五页版式设计：从真实五页样章拆解每一页的目的和信息密度。
07. 自动排版：运行一个仅直接依赖ReportLab的新写示例，生成五页布局PDF。
08. 质检清单：用“问题—可能原因—修正方法”审阅文字、图片和活动。
09. 亲子使用：把阅读、找物和表演排成可调整的一周安排。
10. 迁移到医学场景：使用虚构材料练习信息拆解，不把教育示例变成医疗建议。
11. 总结与作业：用五页作品、来源表和质检记录展示可重复的流程。
