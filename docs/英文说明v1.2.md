A static HTML course for medical researchers and AI learners. Lessons are in Chinese, with reusable prompts and runnable examples. All reader profiles and medical scenarios are fictional. Project creator, adaptation organiser and maintainer: **Haixiang Ding, MD**, emergency and trauma surgeon, Clinical Medicine PhD student at Soochow University.

**AI disclosure:** the existing comic companions were organised with Hark assistance. Codex assisted with course text, teaching prompts, HTML/CSS/JS, SVG code and Python/JSON examples. The new concept cover was generated with the built-in OpenAI image generation tool; it is neither a book illustration nor an actual product screenshot. New prompts and code are teaching examples, not original production records. Original cast sheets, model/package details, image references and prompt logs remain **pending**. The current direct Codex content review is an AI-assisted review, not independent human, legal or medical expert sign-off. Earlier failed Hark reviews remain incomplete.

## Quick start

Open the [online course](https://tuanziding.github.io/comic-companion-course/) or download the full repository and run:

```sh
python3 -m http.server 8875 --bind 127.0.0.1
```

Keep the server running and open `http://127.0.0.1:8875/` in Chrome. No build system, API account or key is needed. Local assets have no CDN, analytics or external font dependencies. A complete download works offline through the local server; external references and GitHub contact links need internet access.

Run the five-page teaching example:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r examples/示例依赖v1.0.txt
.venv/bin/python examples/排版示例v1.1.py
```

Only reportlab is a direct dependency; its dependencies install automatically. Windows users should use the virtual environment's Scripts/python. The default input is examples/章节数据v1.1.json and output examples/输出/五页排版示例v1.1.pdf. Optional arguments: `--data PATH --output PATH`. Built-in Helvetica demonstrates English layout; Chinese notes remain in JSON/HTML. Illustration areas are explicitly marked placeholders.

<a id="workflow"></a>
## Workflow

Lawful source → fictional reader → event boundary and six panels → character states → text-free illustrations → shared utterance IDs and five-page layout → rendered review and corrections.

Every lesson includes goals, explanation, an actual PDF case, a copyable teaching prompt, checklist and assignment. The twelve lessons cover introduction, readers, selection/rights, adaptation, cast continuity, image generation, layout, ReportLab, quality checks, family use, medical transfer and final submission.
